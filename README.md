# Quipá — Acessibilidade e Inclusão

O Quipá é um protótipo web responsivo que reúne recursos simples para apoiar acessibilidade, comunicação e autonomia digital.

## Recursos

- **Leitor de texto:** converte texto em fala usando a síntese de voz disponível no navegador, configurada para português do Brasil.
- **Comunicação rápida:** frases prontas que podem ser reproduzidas em voz alta.
- **Personalização visual:** tamanho do texto, alto contraste, fonte de leitura e opção de reduzir movimentos.
- **Navegação acessível:** atalho para pular ao conteúdo principal, rótulos de formulário e foco visível para teclado.
- **Preferências locais:** configurações de acessibilidade são salvas no navegador do usuário.

## Como executar

Abra `index.html` em um navegador moderno ou publique os arquivos em uma hospedagem estática, como o GitHub Pages. Não é necessário instalar dependências.

## Estrutura

- `index.html` — estrutura e conteúdo da interface.
- `style.css` — estilos responsivos e modos de acessibilidade.
- `script.js` — leitura em voz alta, controles e preferências.

## Observação

Este é um protótipo inicial. A compatibilidade da leitura em voz alta depende do navegador e das vozes instaladas. O projeto ainda precisa de testes de acessibilidade com pessoas com deficiência e tecnologias assistivas.
